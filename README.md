# Loafly Orders Pipeline

A refactor of Loafly's nightly order-processing script into a small,
production-ready Python package — built as part of the Codebasics Data
Engineering Bootcamp, Session 4.

- **`starter/`** — the original broken script, as provided
- **`working/`** — the refactored package (see `working/README.md` for
  full details, setup, and how to run it)
